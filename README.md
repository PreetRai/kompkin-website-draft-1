# Kompkin Website Draft 1

A self-contained static redesign of the Kompkin education website.

## Preview

This project is designed for GitHub Pages and can be opened directly from the published site root.

## Structure

- `index.html` - home
- `about.html`, `achievements.html`, `awards.html`, `team.html` - company pages
- `csr.html`, `donate.html`, `telltale.html` - CSR and impact pages
- `casestudy.html`, `saksham.html` - case studies
- `products.html`, `equipment.html` - products and classroom systems
- `resources.html`, `demos.html`, `news.html` - resources and updates
- `contact.html`, `career.html`, `privacypolicy.html` - utility pages
- `404.html`, `robots.txt`, `sitemap.xml` - technical SEO and fallback files
- `assets/images/` - locally stored website imagery

The contact and enquiry forms currently use email links and should be connected to a production form endpoint before launch.
